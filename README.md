# PTIT Event Hub

A full-stack event discovery and registration platform for PTIT students.

## Features

- Browse upcoming events
- Search events
- Filter by category
- Event detail pages
- Event registration
- Prevent duplicate registrations
- Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Architecture

Next.js
   ↓
Supabase
   ↓
PostgreSQL
